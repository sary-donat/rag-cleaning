# 🧽 עוזרת הניקיון – מערכת RAG

מערכת שעונה על שאלות בענייני ניקיון (למשל: *"באיזה חומר מומלץ לנקות ספת עור?"*)
על סמך מאגר מסמכים, ומציגה את המקורות שעליהם התבססה התשובה.

## בסיס הידע (`data/`)
| קובץ | נושא |
|---|---|
| `01_furniture.md` | ספות עור ובד, רהיטי עץ, מזרנים |
| `02_kitchen.md` | תנור, כיריים, מיקרוגל, מקרר, נירוסטה |
| `03_bathroom.md` | אבנית, עובש, מקלחון, אסלה |
| `04_stains_laundry.md` | כתמים בבגדים וכביסה |
| `05_floors_windows.md` | רצפות, חלונות, מראות, שטיחים |
| `06_materials_safety.md` | חומרי ניקוי נפוצים וכללי בטיחות |

## ארכיטקטורה

```
שלב האינדוקס:
  מסמכים (data/) → טעינה → חלוקה ל-Chunks → Embeddings → Vector Store (storage/)

שלב השאלה:
  שאלה → Embedding → אחזור 5 מקטעים דומים → סינון לפי סף דמיון
       → LLM (Claude) מנסח תשובה מהמקטעים → תשובה + מקורות
```

| קובץ | תפקיד |
|---|---|
| `rag.py` | כל לוגיקת ה-RAG: טעינה, Chunking, Embeddings, Retrieval, יצירת תשובה, מקורות |
| `app.py` | ממשק משתמש ב-Streamlit |
| `test_questions.py` | הרצת שאלות בדיקה |

## בחירות טכנולוגיות
| רכיב | בחירה | למה |
|---|---|---|
| ספריית RAG | **LlamaIndex** | דרישת התרגיל. כל השלבים ממומשים באמצעות רכיבים מוכנים שלה. |
| חלוקה ל-Chunks | `SentenceSplitter` (800 טוקנים, חפיפה 100) | חותך בגבולות משפטים, כך שמקטע לא נקטע באמצע משפט. |
| Embeddings | `intfloat/multilingual-e5-small` (HuggingFace) | תומך בעברית, רץ מקומית ובחינם. המודל דורש תחילית `query:` לשאלות ו-`passage:` למקטעים. |
| Vector Store | ה-Vector Store המובנה של LlamaIndex, שנשמר בתיקייה `storage/` | פשוט, לא דורש התקנה נוספת, ומתאים למאגר קטן. |
| LLM | Claude (`claude-haiku-5-5`) דרך `llama-index-llms-anthropic`, בלי שלב חשיבה ועד 1000 טוקנים | מהיר וזול, ומתאים לניסוח תשובה קצרה מתוך מקטעים שכבר אוחזרו. |
| ממשק | Streamlit | ממשק פשוט שנכתב כולו בפייתון. |

**טיפול בשאלה שאינה במאגר:**
1. מקטעים עם ציון דמיון נמוך מ-0.5 מסוננים. אם לא נשאר אף מקטע, מוחזרת התשובה "לא מצאתי מידע על כך במאגר".
2. הפרומפט מורה למודל לענות רק לפי המידע שאוחזר, ואם אין בו תשובה, להחזיר את אותה הודעה.

## הוראות הרצה
1. התקנת הספריות:
   ```bash
   pip install -r requirements.txt
   ```
2. יוצרים קובץ `.env` (לפי `.env.example`) ומכניסים בו את `ANTHROPIC_API_KEY`.
3. בניית האינדקס (בהרצה הראשונה מודל ה-Embeddings יורד מהאינטרנט). השלב הזה לא חובה: אם התיקייה `storage/` לא קיימת, האינדקס נבנה אוטומטית בהפעלה הראשונה.
   ```bash
   python rag.py
   ```
4. הפעלת הממשק:
   ```bash
   streamlit run app.py
   ```
5. הרצת הבדיקות:
   ```bash
   python test_questions.py
   ```

> אחרי שינוי במסמכים שב-`data/` מריצים שוב `python rag.py` כדי לבנות את האינדקס מחדש.
